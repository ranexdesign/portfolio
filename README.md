# Ranex Design — Pricing Website

A responsive, single-page pricing website for Ranex Design.

## Files
- `index.html` — complete website (HTML, CSS, and JavaScript are included in one file).

## Run locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` to the repository's **root** (not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for GitHub Pages to finish deploying. Your site URL will appear in the Pages section.

## Before publishing
Check that the WhatsApp number, email address, portfolio URL, prices, and service deliverables are correct. The page currently loads Archivo and DM Sans from Google Fonts; it still works with system fonts if those fonts cannot load.
